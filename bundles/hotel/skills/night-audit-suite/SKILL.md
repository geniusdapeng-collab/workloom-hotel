# 夜审技能

## 〇、定位：夜班定义（酒店版）中的夜班值守职责

夜班 = 人类免打扰时段的系统运行模式（锚的是"人的离线"，不是"AI 的工作时间"）。在酒店场景它是**值守型**：夜间入住接待、客需应答、无人店断点兜底，以及本技能承担的**夜审对账**——把过去前台每晚 1–2 小时的手工四源比对，变成业务发生瞬间即已核账、清晨只看差异项。触达免打扰（差异项进清晨决策包）、权限自降级（差异 review、担保 block）由夜班体系统一承载。


## 适用场景
- 每日 23:00–01:00 自动夜审（夜班班组核心场景）

## 触发条件
- 每日 23:00 定时

## 输入数据
- PMS 房态/订单、OTA 渠道账单、收银记录、押金台账

## 方法
1. 五核对：房态（在住/空房/维修）× 订单（今日入住/退房/取消）× 收入（房费/杂费）× 收款（现金/线上/挂账）× 押金（收取/退还）。
2. 差异识别：可解释差异记录原因；不可解释差异标「需介入」进清晨决策包。
3. 口径一致：与 channel-reconciler 对账口径保持一致（唯一事实源）。
4. 报表生成：夜审报表自动写入事件库，进清晨决策包「已完成」栏。

## 输出动作
- 夜审报表 + 差异清单（需介入项 ≤20 条进决策包）

## 对接系统
- PMS/OTA/财务

## 围栏绑定
- 差异 → review；担保异常 → R5 block

## 验收用例
- 正常路径：五核对全通过 → 夜审报表生成 → 决策包「已完成」
- 异常路径：某数据源缺失 → 该核对项标 nodata → 报表注明不编造
- 围栏触发：夜审差异不可解释 → 标需介入不自动平账；担保异常 → R5 block
