## 我们相信的一件事

中国酒店业的绝大多数，是 20–50 间房的单体酒店、5–20 间房的民宿、和正在兴起的无人酒店。它们贡献了行业最多的房间，却用着最原始的经营方式——店长一个人活成前台、客服、财务、采购和维修工，夜班前台一年换三茬，老板的手机 24 小时不敢静音。

大酒店集团用得起收益经理、夜班团队和数据中台。**小酒店不是不需要，是一直没人给他们造得起。**

WorkLoom 就是为这件事来的：**把过去只有大酒店集团才拥有的经营能力，装进每一家小酒店里。** 这不是给酒店多一个软件，是给酒店换一种活法。

## 一、您的酒店，值得这样经营（写给经营者 · 70%）

### 1.1 您未来的一天

> **08:30** 您在早餐店打开手机。夜班班组的决策包已经到了：「昨夜完成 9 项——夜审零差异、竞对价格卡 ×3、房价微调 ×2；1 项待您批准；0 项需要您操心。」您喝着豆浆点了个「采纳」，3 分钟开完「晨会」。
>
> **10:00** 系统提醒：国庆价格矩阵已按历史曲线和竞对生成，您审了一遍，确认发布——750 个价格点自动同步 6 个渠道。
>
> **14:00** 入住高峰，前台没排队：智能排房避开了所有问题房，自助入住 3 分钟办结。
>
> **16:30** 手机一震：飞猪一笔促销价设置失误触发倒挂，系统已经熔断拦截——损失为零。过去这种事月底对账才发现。
>
> **22:00** 夜班班组准点出征。您关了手机，去看孩子的家长会。
>
> **夜里 01:20** 有客人问 WIFI，AI 语音前台 2.8 秒回复。有客人投诉噪音，系统安抚后转值班手机——**没有打给您**。

这不是概念片。这是系统里每个工作日真实发生的流程——您可以亲手点一遍。

### 1.2 您的店正在漏钱，而且漏得无声无息

单体酒店同时挂着 6–8 个 OTA 渠道，带来行业性的「三失」——**失控**（价格倒挂、超售漏售）、**失时**（调价回评慢半拍）、**失准**（信息不同步、决策靠感觉）。行业测算每年吞掉单体酒店 3–8% 营收——一家年营收 100 万的店，就是 3–8 万，**相当于白养一个前台**。

更深一层：店长每天 5.5 小时耗在机械重复上（改价、对账、回评、做表），真正值钱的经营判断反而没时间做。夜班前台是人力结构最脆弱的一环——**招聘难、留人难、出错难究**，年薪 4–6 万还留不住人。

### 1.3 换一种活法：七件消失的事

这套系统最值钱的不是自动化，是**经营方式的重构**——回到每件事的目的，用全新方式达成，让原来的工作本身消失：

| 原来的事 | 现在 |
|---|---|
| 每晚 1–2 小时**夜审** | 每笔业务发生瞬间即已核账——**夜审这个动作消失**，清晨只看差异项 |
| 手写**交接班**本 | 下一班直接查系统投影，30 秒电子签收——**交接从转述变成查询** |
| 店长每天**手动调价** | 价格在安全边界内成为连续函数，店长只做策略家——**策略即配置** |
| **差评**隔夜才发现 | 分钟级推送+AI 起草，防御窗口前移到客人离店**之前** |
| 月底**做报表** | 经营问题用自然语言直接问，秒级出数——**报表作为产物消失** |
| 前台**接电话** | AI 语音前台 24 小时应答，前台只剩一条「例外通道」 |
| 无人酒店**断点**靠人肉 | 每个断点强制根因闭环，系统越用越少断点——**第 5 家店比第 1 家更好管** |

### 1.4 三笔账，算给您听

**💰 降本：每天省 5.5 小时，年化约 9.8 万。** OTA 数据收集、改价、对账、夜审、做表、回评六大机械劳动被接管。其中夜班岗位一项年化省 2.8–4.2 万——**仅此一项即覆盖全年订阅**。

**📈 增收：堵住六大流失点，年化约 7.2 万。** 调价不及时（占流失 40%）挽回约 70%、差评响应（20%）挽回约 80%、超售漏售（15%）拦截 90%、对账差异（10%）发现 95%。

**🚀 规模：一个人管 5–8 家店。** 业主驾驶舱一屏看全部门店，决策包汇聚、告警收敛、断点率排名——管理半径翻倍，而人不用增加。

> 中性测算年化价值约 17 万/店；最保守情景 11.5 万，仍是订阅费 3 倍以上。（示例测算，可按您门店实际情况替换）

### 1.5 三种店，三种答案

> **客户旅程（零风险先行）**：**先体检，再托管**——新客户默认从「质检模式（Audit-Only）」起步：接上 PMS/OTA 数据后系统**只读扫描、不写回一个字**，五线巡检（价格健康：多 OTA 倒挂/低于保底价/促销失误；房态库存健康：超售漏售/问题房；渠道健康：佣金错算/对账差异；口碑健康：存量未回差评/SLA；安全与合规：担保订单异常/断点高频项），异常按 P0/P1/P2 分级，产出《酒店体检报告》（一店一份+整改建议，按年化挽回金额排序）。您在 PMS/OTA 侧人工处置、系统跟踪闭环；看到漏的钱之后，再一键切换影子模式（3 天只看不做）→ 正式托管。**体检分两档**：⚡ **快照快扫**（fast-scan 技能）——授权后 15–30 分钟基于 90 天历史快照完成五线深度扫描，**当场出《酒店快速体检报告》**；🔍 **持续体检**（inspection-suite，1–2 周）——捕捉差评响应实测/SLA 履约/夜班断点等只有时间能回答的问题。围栏纪律：体检期一切写操作物理 block（`fences/patches/audit-only-patch.yml`）。

**🏨 低星单体酒店（20–50 间）**：一年省 17 万，一个月回本。夜班、调价、对账、差评四大出血点一次堵上。

**🏡 民宿（5–20 间）**：**把夜晚还给业主。** 语音前台 24 小时在线，晚上您可以关机；小红书/抖音内容营销前置——种草是民宿的命脉，系统懂。

**🤖 无人酒店**：断点不是事故，是资产。根因强制闭环让断点率逐周下降；三级兜底（AI→远程→现场）+ 业主驾驶舱，一个店长管好 5–8 家店。

### 1.6 比省钱更重要的：经验不再随人走

酒店业年流失率 30–50%。优秀店长的调价手感、客诉话术、排班心得，过去都装在个人脑子里，人一走，经营质量断崖。

在这套系统里，经验会沉淀为**技能与组织记忆**：高频工作自动固化为 SOP 和触发器，好店长的打法变成全店的资产。**新员工入职第一天，就站在前任全部经验的肩膀上。** 这不只是效率，是您这家店的「经营保险」。

## 二、AI 班组如何做到这一切（写给关心机制的人 · 30%）

### 2.1 一支编队，而不是一个聊天框

WorkLoom 的 AI 不是「一个助手」，是**一支有分工、有纪律、有状态机的 Agent 班组**：

- **夜班班组**：每晚 22:00 自动出征——竞对采集 → 三轮对账 → 房价微调 → 清晨 08:30 交付三段式决策包（✓已完成/◆待审批/▲需介入）。任意时刻一键暂停，60 秒内全端生效，恢复后断点续跑。

  > **夜班的定义（酒店版·值守型）**：夜班锚的从来不是"AI 的工作时间"——AI 本来就 24 小时全勤——而是**"人的离线时间"**。它是**人类免打扰时段的系统运行模式**：① 触达上免打扰（非 P0 不叫人，聚合为清晨决策包）；② 权限上自降级（夜班微调 ≤3% auto、越线挂起，人不在线时系统把权力收小）；③ 酒店的高峰窗口是**夜班值守**——夜间入住接待、客需应答（语音前台）、夜审对账、无人酒店断点三级兜底；④ 成本上是洼地（对账/报表在谷时算力窗口执行）。一句话：**夜班服务的不是"夜晚"，是"人的离线"——把夜晚还给业主。**
- **技能市场**：25 个官方技能套件（夜班夜审、收益经理、渠道对账、倒挂超售看门狗、差评危机、语音前台、断点根因闭环……）是**可见、可装、可迭代的资产**，每项技能都带验收用例；使用采纳率回流驱动迭代。
- **意识系统**：高频重复工作被自动检测，每周产出「固化建议」——您一键确认，系统就把这件事变成自动触发器。**系统每周都比上周更懂您的店。**

### 2.2 数字CEO：让您的酒店有一位真正的总经理

过去两年，我们给酒店配齐了数字员工：调价的、回评价的、夜班值守班的、做内容的。但酒店业主们很快发现了一个新问题——**员工越强，老板越忙**：每条策略要自己串，每个异常要自己判，每个动作要自己批。数字员工解决的是「手」的问题，没解决「脑」的问题。

人类的酒店总经理做什么？三件事：**做决策、带团队、向董事会汇报**。数字CEO 就是把这三件事机器化——它统领全部数字员工，对经营结果负责，您（董事长）只做三件事：**提目标、听汇报、批少数关键决策**。

| 场景 | 有了数字CEO 之后 |
|---|---|
| 每天调价 | 微调价它秒级直批；大幅调价走**六步深度分析**（情报→案例回忆→多方案→红队挑刺→影响预估→建议书），重大决策试用期一律请您拍板 |
| 差评与投诉 | 常规它自主闭环；涉赔偿/公开承诺，形成「情况-选项-建议-依据」请示单，您 30 秒批完 |
| 夜班 | 夜班战队照旧干活，但次日汇报从「罗列事项」升级为 CEO 晨报：**做了什么/结果如何/需要您决策 0-N 件** |
| 团队管理 | 每周给每个数字员工打分（表扬/关注/辅导）；连续不达标的，它出具**汰换诊断书+新员工设计方案**报您批准——**汰换不是删除，是基因重组** |
| 多店经营 | 单店一位「公司CEO」，多店之上一位「集团CEO」向您负全责——**一人管 5-8 家店的管理半径**，靠的就是这个编制 |

**运行机制（可信比聪明更重要）**：

- **默认关闭**：每家店的数字CEO 出厂即关闭；启用须您亲手完成**六步深度授权**（风险揭示/逐条确认/边界三滑杆/试用计划/身份核验/签署留痕）；
- **先影子后试用**：先当 3 天「影子」只模拟不执行，再 7 天试用（权力自动减半），**到期不自动续期**，长期保留或按季续任由您定；
- **五级权限**：小事它定（L2 公司CEO 裁决），跨店/大额归集团CEO（L3），涉大钱/人/品牌/围栏放宽必请您（L4），安全禁区物理熔断（L5）；
- **经营剧场**：打开系统首页就是经营剧场——数字CEO 与团队的全息形象站在舞台中央，晨报它主动讲，请示它举着等您批，您有空看一眼，没空它也把店看得好好的；
- **全链留痕**：它的每一个决策、您的每一次授权与批准，都写进不可篡改的事件账（哈希链可验）。

> **立即体验**：`pnpm demo:twin:restore && pnpm dev` → 打开首页即是经营剧场（云栖酒店已有一位试用期中的公司CEO）；左侧「董事长视图」可体验授权、裁决、绩效评议与汰换提案全流程。

### 2.3 安全不是承诺，是物理约束

- **围栏引擎 R1–R20**：一切动作 100% 经过三级判定——`auto` 放行 / `review` 挂起等您 30 秒审批 / `block` 熔断告警。低于保底价？**系统物理上无法执行**，这不是提醒，是拒绝。
- **拒绝默认**：数据缺失时系统熔断而非猜测；多条规则命中取最严（deny 优先）；基线**只可收紧不可放宽**——任何自定义都在让系统更安全。
- **三手势审批**：涉钱、涉客、涉对外的动作，必须您看清快照、给一句话理由、做一个手势。机器做 99%，**人的权威保留在最关键的 1%**。
- **安全禁区**：火灾、治安等安全事件，AI 只告警+联动报警，**绝不自行处置**——红线写死在系统里，不靠模型自觉。

### 2.4 每一条记录都可以被验证

全部经营动作以五元事件（谁/何时/对什么/做了什么/规则影响）写入**哈希链**——逐条 SHA 锁定，包括系统自己的操作也不可篡改。多租户行级隔离、凭据不落明文、敏感信息脱敏入档。信任不靠品牌背书，**您可以当着我们的面逐条重算**。

### 2.5 产品理念：四个「反直觉」的坚持

> **拒绝默认**——宁可错杀，不可错放。
> **只紧不松**——围栏只能变严，不能变松。
> **断点是资产**——每次做不到，都必须让系统下次做得更好。
> **把夜晚还给业主**——技术的终极指标，是人能不能睡个整觉。

## 三、通用模型路由系统（酒店版接入）

酒店版全面接入底座 v3.0 通用模型路由（详见 [workloom-im](https://github.com/geniusdapeng-collab/workloom-im)）：**每一个 AI 调用点都按场景路由到最合适的模型——高频轻量用小模型又快又省，深度决策用旗舰模型质量拉满，每一次消耗逐事件计量可审计。**
